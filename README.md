# Songstery

Музичні рекомендації до книг і окремих розділів для україномовної аудиторії.

Користувач знаходить книгу, бачить пісні, які до неї радять інші читачі, збирає плейлисти та радить власні треки
до всієї книги або до конкретного розділу. Якщо трек уже хтось додавав, його можна порадити в один клік.

## Можливості

- Каталог книг, пошук по каталогу та по Google Books (лише українські видання), імпорт книги в один клік
- Рекомендації треків (YouTube, Spotify) до книги та до розділу, групування за треком із лічильником
- Автоматичне підтягування назви та виконавця за посиланням (oEmbed, без API-ключів)
- Плейлисти, зібрані з треків, які вже порадили до книги
- Коментарі з відповідями
- Верифікація авторів із приватним сховищем документів
- Багатокроковий майстер реєстрації, вхід через Google
- PWA, sitemap, robots.txt

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python manage.py migrate
python manage.py sync_site
python manage.py createsuperuser
python manage.py runserver
```

Мінімально потрібні `SECRET_KEY` та `DEBUG` у `.env`. Без `DATABASE_URL` використовується SQLite, без `REDIS_URL` кеш
і ліміти запитів працюють у пам'яті процесу (для кількох воркерів задайте `REDIS_URL`).

## Тести

```bash
python manage.py test tests
```

## Структура

```
core/
  models/      книги, музика, коментарі, профіль, верифікація
  services/    уся бізнес-логіка: каталог, Google Books, посилання на треки, рекомендації
  views/       тонкі в'юхи за областями
  forms.py     форми
tests/         тести моделей, сервісів і в'юх
```

Налаштовувані значення (ліміти, таймаути, адреси зовнішніх сервісів, розміри сторінок) зібрані в `songstery/settings.py`.
Підтримувані музичні платформи описані в одному місці — `core/services/music_links.py`.

## Конфігурація

| Змінна | Призначення |
| --- | --- |
| `SECRET_KEY`, `DEBUG`, `ALLOWED_HOSTS` | базові налаштування Django |
| `SITE_NAME`, `SITE_DOMAIN`, `SITE_URL` | назва та адреса сайту |
| `DATABASE_URL`, `REDIS_URL` | база даних і кеш |
| `GOOGLE_BOOKS_API_KEY` | ключ для пошуку книг (значно збільшує квоту) |
| `PRIVATE_MEDIA_ROOT` | каталог для документів верифікації; у проді має бути постійним і недоступним ззовні |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | вхід через Google (якщо не задано, кнопка не показується) |
| `EMAIL_*`, `DEFAULT_FROM_EMAIL`, `ADMIN_EMAIL` | пошта для сповіщень про верифікацію |
| `SENTRY_DSN`, `PLAUSIBLE_DOMAIN` | моніторинг і аналітика |

## Розгортання

`build.sh` встановлює залежності, збирає статику, застосовує міграції, синхронізує `Site` та створює суперкористувача
зі змінних `DJANGO_SUPERUSER_*`.
